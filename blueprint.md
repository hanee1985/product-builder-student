
# Lotto Number Generator

## Overview

This project is a simple web application that generates and displays a set of 6 unique random lottery numbers between 1 and 45. The user can click a button to generate a new set of numbers.

## Current Plan

### Step 1: HTML Structure (`index.html`)

*   Set the title to "Lotto Number Generator".
*   Create a main container for the application.
*   Add a heading for the title.
*   Add a container to display the generated lottery numbers.
*   Add a button to trigger the number generation.

### Step 2: Styling (`style.css`)

*   Apply a clean and modern design to the page.
*   Style the main container, title, number display area, and the "Generate" button.
*   Use a color-coded system to display the lottery numbers based on their value ranges, enhancing visual appeal.

### Step 3: JavaScript Logic (`main.js`)

*   Implement a function to generate 6 unique random numbers from 1 to 45.
*   Attach an event listener to the "Generate" button.
*   When the button is clicked, call the number generation function and display the numbers on the page.
*   Each number will be displayed in a styled element.
